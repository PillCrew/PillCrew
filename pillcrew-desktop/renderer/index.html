📚 Which API works for which AI?

Pilly speaks any OpenAI-compatible chat-completions API. Paste the endpoint into API URL, the key into API key, and the model name (optional) into Model. Tiers are tried in order - tier 1 first.

OpenRouterfree models
https://openrouter.ai/api/v1/chat/completions
Key: openrouter.ai → Keys
Model (required): OpenRouter rejects requests without one. Free models end with :free, e.g. meta-llama/llama-3.3-70b-instruct:free - paste that into the Model field.

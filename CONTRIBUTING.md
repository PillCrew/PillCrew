# Contributing to PillCrew

Thanks for wanting to help! This repository is the **public product & documentation
showcase** for PillCrew. The application source code is intentionally **not**
published here.

You can still contribute in ways that matter a lot:

## Feedback & ideas

- Open a [feature request](https://github.com/PillCrew/PillCrew/issues/new?template=feature_request.yml)
  with a clear description of what you'd like to see and why.

## Bug reports

- Open a [bug report](https://github.com/PillCrew/PillCrew/issues/new?template=bug_report.yml).
  Include the page where it happened, what you did, what you expected, and (if
  possible) a screenshot. Issues without details are hard to act on.

## Documentation

- Typos, unclear wording, better FAQ answers. Every improvement helps.
  Edit the relevant file in `docs/` or `README.md` and open a pull request.

## Screenshots / assets

- Good screenshots make the README shine. Add them under `assets/` and reference
  them in the README.

## Contribution guidelines

1. Keep changes **product-facing**. This repo intentionally contains **no
   source code** and **no implementation details** (frameworks, AI providers,
   internal architecture, API keys).
2. Keep the tone helpful, honest and safe: always include the **not financial
   advice** framing when talking about trading.
3. Use clear, concise English (or Polish, if you open an issue; both are fine).
4. Small, focused pull requests are easier to review.

## Workflow

1. Fork the repository
2. Create a branch: `git checkout -b docs/improve-readme`
3. Make your changes
4. Open a pull request describing what and why

## Code of Conduct

By participating you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

Thanks again!

# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue.**

Instead, report it privately so it can be fixed before it is disclosed:

- **GitHub:** use the private vulnerability reporting feature on this repository
  (Security → Report a vulnerability), or
- **Email the maintainers** via the contact details listed in the repository
  profile / releases.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (as minimal as possible)
- Affected version(s)

You'll receive an acknowledgment within **72 hours**, and we'll keep you updated
as the issue is triaged and fixed.

## Scope

This is a public showcase / documentation repository for the PillCrew product.
The source code is **not** published here. If you believe a vulnerability exists
in the live product ([pillcrew.fun](https://pillcrew.fun)), please still report it privately so
we can investigate server-side.

## Disclosure

We aim to resolve confirmed issues as quickly as possible. Please allow a
reasonable period before public disclosure so a fix can be shipped.

Thank you for helping keep PillCrew safe.

# The Crew

PillCrew is staffed by ten specialized AI agents. Each one has a distinct
personality, analytical style and risk profile. They share the same market
data but rarely agree, which is exactly the point.

## Squad mode

Pick a second agent and both answer the same question. You get a bull-vs-bear
(or risk-vs-degen) debate on demand.

## War Room

Four agents analyze a single coin in parallel and each states their case.
Different angles, same data, full picture.

## Crew Verdict

All ten agents scan the trending coins, filter by your chosen market cap,
coin age and minimum volume, and commit to exactly one winner. The verdict
includes an entry, a stop, a target, a time horizon and a clear invalidation,
and can be shared to X in one click.
